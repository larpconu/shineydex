# hightail logo

Wordmark: "hightail" in Bricolage Grotesque 800, lowercase, tracking -0.055em,
outlined to paths. The first "i" is a sprinting figure drawn with the same
stroke weight as the letter stems (162 units), round caps and joins, from the
baseline to the top of the "h" ascender; the head sits where the i's dot would be.

| File | Use |
| --- | --- |
| `wordmark-white-on-red.svg` / `.png` | Primary wordmark |
| `wordmark-red-on-white.svg` / `.png` | Wordmark on light backgrounds |
| `wordmark-white.svg`, `wordmark-red.svg` | One-color, transparent background |
| `icon.svg`, `icon-{180,192,512,1024}.png` | App icon: white runner + speed lines on #E5102A |
| `icon-white.svg`, `icon-red.svg` | One-color icon mark, transparent background |
| `favicon.svg`, `favicon-{16,32,48}.png`, `favicon.ico` | Runner only |

Regenerate with `python3 tools/make_hightail_logo.py <BricolageGrotesque variable TTF>`
(pose coordinates live at the top of that script).
